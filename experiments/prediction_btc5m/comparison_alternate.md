# 每期固定交替方向＋亏损递增

数据：2026年8月Binance BTCUSDT现货5分钟K线。100U起投，第一笔1U，亏损按累计亏损加1U目标计算续投金额，整轮盈利重置1U。每根K线都切换方向（包括平盘），不受输赢或重置影响。

假设固定成交价格、零费用、立即入场、平盘退款、持有到结算。90%提前续投及95%退出均 unavailable。买入0.60表示每次买入所选方向都花0.60，不代表两个方向同时报价0.60。最高余额是逐期已结算余额。

|起始方向|假设买入价|最高U|最终U|首次断链小时|每日独立起点断链数|已断链中位小时|
|---|---:|---:|---:|---:|---:|---:|
|UP|0.5|1979.00|956.00|308.33|31/31|6.50|
|UP|0.6|121.00|43.87|4.17|31/31|4.17|
|DOWN|0.5|136.00|9.00|6.67|30/31|10.08|
|DOWN|0.6|112.00|34.87|2.92|31/31|2.92|

首笔UP、0.50的单次路径达到1979U，之后连续10笔失败损失1023U，剩956U不足以投入下一笔1024U，故停止。这是马丁断链，并不意味着余额归零或累计亏损。该路径最终比100U本金多856U，但不能据此推断稳定日收益。首笔DOWN在同样价格假设下只剩9U。

每日起点均从UTC 00:00独立投入100U并重新设置指定起始方向，观察到8月底。样本相互重叠；月底未断链为右删失，不能当作长期安全。切换起始方向是预先同时比较的两种情景，不能事后选择有利方向作为策略表现。

复现：
```sh
.venv/bin/python -m binance_quant.prediction_scenario --mode alternate --first-side UP
.venv/bin/python -m binance_quant.prediction_scenario --mode alternate --first-side DOWN
.venv/bin/python -m unittest discover -s tests -p test_prediction_research.py -q
```
